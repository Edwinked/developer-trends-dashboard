# Developer Trends Dashboard

IBM Data Analyst Capstone Project - dashboard created from the Stack Overflow developer survey data.

Dashboard file: Developer-Trends-Dashboard.pdf

Tabs included:

- Current Technology Usage - top 10 languages, databases, platforms and web frameworks developers have worked with
- Future Technology Trend - top 10 languages, databases, platforms and web frameworks developers want to work with
- Demographics - age distribution, developers around the world, education level, and education level by age
